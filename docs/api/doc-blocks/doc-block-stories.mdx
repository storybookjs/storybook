The `Stories` block renders the full collection of stories in a stories file.

![Screenshot of Stories block](../../_assets/api/doc-block-stories.png)

```mdx title="ButtonDocs.mdx"
import { Meta, Stories } from '@storybook/addon-docs/blocks';
import * as ButtonStories from './Button.stories';

<Meta of={ButtonStories} />

<Stories />
```

## Stories

```js
import { Stories } from '@storybook/addon-docs/blocks';
```

`Stories` is configured with the following props:

### `includePrimary`

Type: `boolean`

Default: `true`, except on an autodocs page whose primary story renders in an iframe (`parameters.docs.story.inline: false`)

Determines if the collection of stories includes the primary story.

On an autodocs page the [`Primary`](./doc-block-primary.mdx) block already shows the primary story, and a story in an iframe loads a whole preview, so by default the page shows a primary story that renders in an iframe once. Set `includePrimary={true}` to list it in the collection anyway. In an MDX file the collection includes the primary story unless you set `includePrimary={false}`.

<Callout variant="info" icon="💡">

Set `includePrimary={false}` to omit the primary story from the rendered collection. If the primary story is the only story in the file, the `Stories` block will render nothing.

</Callout>

### `title`

Type: `string`

Default: `'Stories'`

Sets the heading content preceding the collection of stories.
