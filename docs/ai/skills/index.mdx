<If renderer={['react', 'vue', 'angular', 'svelte', 'web-components', 'solid']}>

Storybook's skills tell your agent how to work with Storybook in your project. Each skill gets its instructions from your installed Storybook, so they match your framework and Storybook version. To install them, see [Connect your agent](../connect.mdx#install-the-skills).

- **Init** (`/storybook-init`): add Storybook to a project that doesn't have it. The [Setup](./setup.mdx) page shows the prompt to use.
- [**Setup**](./setup.mdx): configure Storybook for your project and write the first stories.
- **Upgrade** (`/storybook-upgrade`): upgrade Storybook by following the [upgrade guide](../../releases/upgrading.mdx#upgrade-with-an-agent).
- [**Component docs**](./component-docs.mdx) (`/component-docs`): look up the components to reuse, with their props and usage examples.
- [**Write stories**](./write-stories.mdx) (`/write-stories`): write stories for every component your agent creates or changes.
- [**Test stories**](./test-stories.mdx) (`/test-stories`): the command that runs the story tests, with their accessibility checks, and what its result means.
- [**UI review**](./ui-review.mdx) (`/ui-review`): create a review of the stories that a change affects, when you ask for one.

`/component-docs` and `/write-stories` are steps of the [Storybook section in `AGENTS.md`](../agents-md.mdx), which your agent follows for every UI change. Its test step is the test command itself, and it ends with a line that offers `/ui-review`.

</If>
