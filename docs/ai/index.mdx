<If renderer={['react', 'vue', 'angular', 'svelte', 'web-components']}>

Storybook helps your coding agent build UI that fits your project. Your agent reuses the components you already have, writes stories for what it builds, tests its work, and gives you a review to check the result.

## What your agent can do

- [**Set up Storybook**](./skills/setup.mdx): configure Storybook for your project and write the first stories.
- [**Change UI**](./skills/ui-workflow.mdx): look up existing components, write or update stories for each change, run story tests with accessibility checks, and publish a review.
- [**Answer questions about components**](./skills/component-docs.mdx): find the right component to reuse and use only the props it documents.
- [**Show you its work**](./skills/agentic-review.mdx): a review groups the stories that a change affects, so you can check them in one place.

## How it works

Storybook gives your agent _skills_: short instruction files in your repository that tell the agent what to do and when. Each skill gets its full instructions from your installed Storybook. The instructions match your framework, renderer, and Storybook version, so they stay correct when you upgrade.

A section in your project's `AGENTS.md` tells your agent when to use the skills. You can edit or remove it.

Agents that can't use skills can connect to the [Storybook MCP server](./reference/mcp-server.mdx) instead.

## Get started

1. [Connect your agent](./connect.mdx) to Storybook.
2. If your project doesn't have stories yet, have your agent [set up Storybook](./skills/setup.mdx).
3. Ask your agent to build some UI. It follows the [UI workflow](./skills/ui-workflow.mdx) and ends with a link to a [review](./skills/agentic-review.mdx).

To get the best results, follow the [best practices](./best-practices.mdx) for documenting your components.
