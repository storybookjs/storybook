---
name: storybook-upgrade
description: Use this skill when Storybook exists but needs an upgrade.
---

Storybook must end up at 11.0 or later. An 11.0 prerelease (`11.0.0-alpha.x`) or a canary build (`0.0.0-pr-*`) also counts.

Read https://storybook.js.org/docs/releases/upgrading.md in its **entirety** to get the latest Storybook upgrade instructions.

If the latest stable release is below 11.0, upgrade to the 11.0 alpha with `npx storybook@next upgrade` instead.
