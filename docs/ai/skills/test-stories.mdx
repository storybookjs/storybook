<If renderer={['react', 'vue', 'angular', 'svelte', 'web-components']}>

The `test-stories` skill lets your agent run your [story tests](../../writing-tests/index.mdx), with their [accessibility checks](../../writing-tests/accessibility-testing.mdx), and fix what fails. Your agent doesn't finish its work with failing tests.

## When your agent uses it

The [Storybook section in `AGENTS.md`](../connect.mdx#tell-your-agent-when-to-use-the-skills) names the test command itself (step 3 of the [UI workflow](./ui-workflow.mdx)), so your agent runs the story tests after every UI change, and when you ask it to run or fix them, without opening this skill. The skill gives the same commands when you or your agent call it by name.

## What the agent does

- **Runs the tests of what it changed.** After each change, the agent runs `npx storybook tools test run --changed`, which tests the stories that its uncommitted changes affect. It can also pass story files, or run every story.
- **Fixes failures.** The agent fixes what fails and runs the tests again. It changes only what the fix needs.

The agent runs the tests with Storybook's own command, never with a test script from your `package.json` or with `vitest` directly.

### Accessibility issues

If you are using the [accessibility addon](../../writing-tests/accessibility-testing.mdx), the agent fixes only the accessibility issues that its change caused, and reports the rest. For visual issues, such as low color contrast, it asks before it changes your design. The agent never changes your accessibility test level to make a test pass.

## Requirements

- The [Vitest addon](../../writing-tests/integrations/vitest-addon/index.mdx), which needs the Vite builder. Without it in your main config, the `AGENTS.md` section has no test step.
- With the [MCP server](../reference/mcp-server.mdx), the [`test` toolset](../reference/mcp-server.mdx#test) turned on

To run accessibility checks with the tests, also install the [accessibility addon](../../writing-tests/accessibility-testing.mdx).
