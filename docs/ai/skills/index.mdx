<If renderer={['react', 'vue', 'angular', 'svelte', 'web-components']}>

Storybook's skills tell your agent how to work with Storybook in your project. Each skill gets its instructions from your installed Storybook, so they match your framework and Storybook version. To install them, see [Connect your agent](../connect.mdx#install-the-skills).

- **Init** (`storybook-init`): add Storybook to a project that doesn't have it. The [Setup](./setup.mdx) page shows the prompt to use.
- [**Setup**](./setup.mdx): configure Storybook for your project and write the first stories.
- **Upgrade** (`storybook-upgrade`): upgrade Storybook by following the [upgrade guide](../../releases/upgrading.mdx#upgrade-with-an-agent).
- [**Component info**](./component-info.mdx) (`component-info`): find components to reuse, compare them, and audit your component library.
- [**UI workflow**](./ui-workflow.mdx): look up components, write stories, run tests, and publish a review for every UI change.

</If>
