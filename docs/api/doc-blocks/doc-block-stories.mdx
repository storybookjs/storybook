The `Stories` block renders the full collection of stories in a stories file.

![Screenshot of Stories block](../../_assets/api/doc-block-stories.png)

```mdx title="ButtonDocs.mdx"
import { Meta, Stories } from '@storybook/addon-docs/blocks';
import * as ButtonStories from './Button.stories';

<Meta of={ButtonStories} />

<Stories />
```

## Stories

```js
import { Stories } from '@storybook/addon-docs/blocks';
```

`Stories` is configured with the following props:

### `includePrimary`

Type: `boolean`

Default: `true`, unless the primary story renders in an iframe ([`inline: false`](./doc-block-story.mdx#inline))

Determines if the collection of stories includes the primary (first) story.

A story in an iframe loads a whole preview, and the [`Primary`](./doc-block-primary.mdx) block already shows the primary story, so by default a docs page shows a primary story that renders in an iframe once. Set `includePrimary={true}` to list it in the collection anyway, for example in an MDX file without a `Primary` block.

<Callout variant="info" icon="💡">

Set `includePrimary={false}` to omit the primary story from the rendered collection. If the primary story is the only story in the file, the `Stories` block will render nothing.

</Callout>

### `title`

Type: `string`

Default: `'Stories'`

Sets the heading content preceding the collection of stories.
