Add `next/link` mock with `useLinkStatus` support. Aliases `next/link`, `@storybook/nextjs/link.mock`, `@storybook/nextjs-vite/link.mock`, and `@storybook/experimental-nextjs-vite/link.mock` to a Storybook-friendly Link mock that records click actions and exposes a mockable `useLinkStatus` hook (defaults to `{ pending: false }`).
