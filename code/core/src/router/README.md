# Storybook Router

Storybook Router is a wrapper library for react-router.
It ensures a single version of the router is used everywhere.
It also includes some ready to use utils to read the path, query, viewMode and storyId from location.

Same-page anchor dispatch retains navigation options, including replacement and
state. Restoring globals or a browser history entry must not create another
history entry when the caller requested replacement.
