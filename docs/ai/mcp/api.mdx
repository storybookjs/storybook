## `@storybook/addon-mcp` options

The MCP server addon accepts the following options to configure the tools provided by the MCP server. You can provide these options when registering the addon in your `main.js|ts` file:

<CodeSnippets path="addon-mcp-options.md" />

### `toolsets`

Type:

```ts
{
  dev?: boolean;
  docs?: boolean;
  test?: boolean;
}
```

Default:

```ts
{
  dev: true,
  docs: true,
  test: true,
}
```

Configuration object to toggle which toolsets are enabled in the MCP server. By default, all toolsets are enabled.

#### `dev`

Type: `boolean`

Default: `true`

The development toolset includes the [`stories-changed`](./overview.mdx#stories-changed), [`get-storybook-story-instructions`](./overview.mdx#get-storybook-story-instructions), [`stories-preview`](./overview.mdx#stories-preview), [`stories-find-by-component`](./overview.mdx#stories-find-by-component), and [`review-create`](./overview.mdx#review-create) tools when their feature requirements are enabled.

#### `docs`

Type: `boolean`

Default: `true`

The docs toolset includes the [`docs-show`](./overview.mdx#docs-show), [`docs-show-story`](./overview.mdx#docs-show-story), and [`docs-list`](./overview.mdx#docs-list) tools.

#### `test`

Type: `boolean`

Default: `true`

The testing toolset includes the [`test-run`](./overview.mdx#test-run) tool when `@storybook/addon-vitest` is installed and enabled.
