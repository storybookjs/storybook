---
name: upgrade
description: Use this skill when Storybook exists but needs an upgrade.
---

Storybook must end up at version 11.0 or later. (While 11.0 is unreleased, the latest `next` prerelease satisfies this. Any canary build, `0.0.0-pr-*`, also qualifies.)

Read https://storybook.js.org/docs/releases/upgrading.md in its **entirety** to get the latest Storybook upgrade instructions.

If the latest stable release is still below 11.0, upgrade to the prerelease instead with `npx storybook@next upgrade`.
